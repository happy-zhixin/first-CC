# first-CC · 音乐精灵

一个存放多个**独立单文件应用**的个人项目仓库。当前主推「🎸 音乐精灵 · 吉他成长」——一个带你从零基础到弹唱流行曲的吉他学习网站。

---

## 🎸 吉他学习站（主打）

**在线访问：** <https://happy-zhixin.github.io/first-CC/>

- **文件：** `guitar-elf.html` —— 单文件，无任何依赖，双击即可本地打开，数据存浏览器本地（localStorage）。
- **理念：** 用「二八定律」抄近路——8 个核心和弦 + 3 条万能和弦进行 + 3 个节奏型，撬动绝大多数流行歌。

### 功能

| 页签 | 说明 |
| --- | --- |
| 路线图 | 五阶段成长路线 + 今日任务 + 总进度条 |
| 30天计划 | 精确到天的练琴计划，可打勾打卡（进度自动保存） |
| 曲库 | 8 首歌，每首含和弦指法图 + 六线谱 + 扫弦节奏 + 卡点 |
| 检测 | 帕累托 5 项自测清单 |
| AI 练琴 | 麦克风实时听音，判断音准（偏高/偏低） |
| 愿景 | 网站 → App → 具身智能「音乐精灵」的路线 |

### 怎么用（手机 / 电脑通用）

1. 打开 <https://happy-zhixin.github.io/first-CC/>
2. 先看「路线图」的**今日任务** → 练完去「30天计划」**点圆圈打勾**
3. 到「曲库」学歌（每首歌有左手按法图 + 右手六线谱）
4. 周末到「检测」自测；用「AI 练琴」校音准

> 📱 手机端：直接用浏览器打开上面的网址即可（无需装 App）。用「AI 练琴」时会请求麦克风权限，点允许即可。

## 🍅 番茄钟

桌面 / 网页双版本，各自独立实现（共享配色，不共享代码）：

- `pomodoro.py` —— 桌面版（Python 3 + Tkinter，仅标准库）
- `pomodoro.html` —— 网页版（原生 HTML/CSS/JS）
- `run.bat` —— Windows 双击启动桌面版

---

## 部署上线

```bash
deploy.bat            # Windows：双击或命令行运行，自动走本地代理推送到 GitHub Pages
```

`deploy.bat` 会提交全部改动并 `git push` 到 `origin/main`，推送成功后 GitHub Pages 会在 1–2 分钟内自动更新。
