# 桌面番茄钟

基于 Python + Tkinter 的单文件番茄钟应用，无需任何第三方依赖。

## 运行

```bash
python pomodoro.py
```

Windows 下也可以直接双击 `run.bat`。

## 功能

| 操作 | 方式 |
| --- | --- |
| 开始 / 暂停 | 点击「开始」按钮，或按空格键 |
| 重置 | 点击「重置」按钮 |
| 跳过当前阶段 | 点击「跳过」按钮 |
| 自定义时长 | 点击右上角 ⚙ |

## 说明

- 默认 25 分钟专注、5 分钟短休息、15 分钟长休息，每 4 个专注进入一次长休息。
- 时间到会播放提示音并自动切换到下一阶段。
- 修改的时长会保存到同目录下的 `config.json`。
