# 桌面番茄钟

基于 Python + Tkinter 的单文件番茄钟应用，无需任何第三方依赖。

## 运行

```bash
python pomodoro.py
```

Windows 下也可以直接双击 `run.bat`。

## 功能

| 操作 | 方式 |
| --- | --- |
| 开始 / 暂停 | 点击「开始」按钮，或按空格键 |
| 重置 | 点击「重置」按钮 |
| 跳过当前阶段 | 点击「跳过」按钮 |
| 自定义时长 | 点击右上角 ⚙ |

## 配色方案

界面采用暖色系配色（奶油米白 + 陶土橙），柔和护眼：

| 用途 | 颜色 | 色值 |
| --- | --- | --- |
| 窗口背景 | 奶油米白 | `#F6F0EB` |
| 主文字 | 暖灰棕 | `#766C65` |
| 进度环底色 | 浅米灰 | `#E5DFD9` |
| 专注（工作） | 陶土橙 | `#C75C46` |
| 短休息 | 暖琥珀 | `#D9A15B` |
| 长休息 | 深棕红 | `#9A4A3A` |

## 配置

修改的时长会保存到同目录下的 `config.json`（该文件已加入 `.gitignore`，不会提交到仓库）。默认值与示例见 [`config.example.json`](config.example.json)：

| 键 | 含义 | 默认值 |
| --- | --- | --- |
| `work` | 专注时长（分钟） | 25 |
| `short_break` | 短休息时长（分钟） | 5 |
| `long_break` | 长休息时长（分钟） | 15 |
| `long_break_interval` | 每 N 个专注进入一次长休息 | 4 |

## 说明

- 默认 25 分钟专注、5 分钟短休息、15 分钟长休息，每 4 个专注进入一次长休息。
- 时间到会播放提示音并自动切换到下一阶段。
- 首次使用会按默认值运行；在设置里修改时长后，才会生成 `config.json`。
